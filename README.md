# TAM Black Friday 2026: Hire Your AI Agent in 3 Days, Live

Funnel for Truly Authentic Marketing, built on the AI Studio app scaffold
(TanStack Start + Vite + React, published by AI Studio as a full-stack app).

## Pages

| Route | Route file | Markup | Job |
|---|---|---|---|
| `/` and `/install` | `src/routes/index.tsx`, `install.tsx` | `src/funnel/pages/index.html` | Sales page. All 11 order buttons go to `/checkout` |
| `/checkout` | `src/routes/checkout.tsx` | `pages/checkout.html` | On-page $97 order form, single product (`src/funnel/CheckoutForm.tsx`) |
| `/growth-accelerator` | `src/routes/growth-accelerator.tsx` | `pages/growth-accelerator.html` | One-click $997 upsell, 6 x $197 plan popup on "No" (`src/funnel/UpsellOffer.tsx`) |
| `/foundation` | `src/routes/foundation.tsx` | `pages/foundation.html` | AI Growth Foundation application, then the booking calendar |
| `/thank-you` | `src/routes/thank-you.tsx` | `pages/thank-you.html` | Booking calendar, Zoom + calendar (.ics) details, teammate form, Product Champ login |

## How it is put together

- **Design and copy are the approved static pages, unchanged.** Each page's body markup lives in
  `src/funnel/pages/*.html` and is server-rendered as is by `src/funnel/FunnelPage.tsx`.
  Edit copy there.
- **Styles, fonts, images, the .ics file** are in `public/static/` (served at `/static/...`).
  The stylesheet is `public/static/css/styles.css`. Tailwind (`src/styles.css`) is part of the
  scaffold but is deliberately not loaded: its reset would change the design.
- **Page behaviour** (reveal on scroll, popups, share link): `src/funnel/funnel.ts`.
- **Payments** use the AI Studio Payments blocks in `src/integrations/payments/` (auto-generated,
  do not edit). The checkout and upsell are embedded on the funnel pages. No external checkout page.
- **Forms** (application, teammate) post to the CRM through `src/funnel/tracking.ts`.
  **Calendar** availability and booking: `src/funnel/calendar.ts`.

## Products and price IDs

Create these three products in AI Studio: More -> Payments.

| Product | Price | Used on |
|---|---|---|
| Hire Your AI Agent in 3 Days, Live | $97 one time | `/checkout` |
| 2027 Growth Accelerator | $997 one time | `/growth-accelerator` |
| 2027 Growth Accelerator, payment plan | $197 a month, 6 payments | `/growth-accelerator` popup |

The funnel finds them three ways, first match wins (`src/funnel/config.ts`, `src/funnel/products.ts`):

1. Env vars: `VITE_BF_MAIN_PRODUCT_ID`, `VITE_BF_MAIN_PRICE_ID`, `VITE_BF_UPSELL_PRODUCT_ID`,
   `VITE_BF_UPSELL_PRICE_ID`, `VITE_BF_PLAN_PRODUCT_ID`, `VITE_BF_PLAN_PRICE_ID`.
2. The `IDS` object at the top of `src/funnel/config.ts`.
3. Automatically, by price, from this project's Payments catalog: exactly one $97 one-time price,
   one $997 one-time and one $197 recurring. If two products share one of those
   prices, set the IDs explicitly.

Until the $97 product exists, `/checkout` shows a "Setup needed" note instead of the order form.

`.env` holds the Payments script URL, catalog API URL and project ID. It is generated by
AI Studio Payments. Do not hand edit those three lines.

## Before launch

- Remove the two `Preview build...` footer notes in `src/funnel/pages/*.html` and the
  `noindex` robots meta in `src/routes/__root.tsx` and `public/robots.txt` when ready to go public.
- Switch Payments from test mode to live mode in AI Studio.
- The CRM workflows keyed on form IDs `foundation-application`, `bf2026-teammate` and
  `bf2026-checkout` apply the tags. Tag $97 buyers from an order / payment trigger: the checkout
  hands the buyer straight to the upsell page.

## Local development

```sh
npm install
npm run dev          # dev server
npm run build        # plain build (dist/client + dist/server)
```

AI Studio publishes the Cloudflare module build (`dist/server/index.mjs` + `dist/client`).
To reproduce that locally:

```sh
VIBE_SANDBOX=1 npm run build
npx wrangler@latest dev -c dist/server/wrangler.json --port 8788
```
